Before you begin

A note for you

Dear Gudiya,

This is a small roadmap for exploring the newest AI tools, the ones that go well beyond typing a question into ChatGPT. Over two weeks you'll set up Claude as a real working partner, hand off whole tasks to Claude Cowork, build interactive tools and dashboards, connect AI to apps like Notion and Google Sheets, and even make a couple of small apps with Claude Code.

You already have exactly the instincts these tools reward: organizing messy information, keeping stakeholders aligned, and turning meetings into clear next steps. AI simply gives those strengths a lot more reach.

Each day has a clear goal, one to three short videos to watch in order, a hands-on exercise built around the kind of project coordination work you do, and a simple checklist so you know when you're done. Many exercises also have a personal side, like travel planning, writing, and ESL lesson plans, because these tools are just as lovely outside of work.

How to use this guide

  • Go at your own pace. “Day 5” just means the fifth step. If a day takes three evenings, that's completely fine, and skipping ahead or circling back is fine too.
  • Watch, then do. Videos are listed in the order to watch them. The exercise is where the real learning happens, so it's okay to watch at 1.5× speed.
  • Tick the boxes. Each day ends with a short “Done when” list. Your ticks are saved in this browser, and the progress bar at the top keeps count.
  • When something breaks, it's the software, not you. These tools change almost weekly, so a button may have moved since a video was recorded. Ask Claude, “Where do I find X in the current app?” It's usually the quickest fix.
A gentle note on work data and company AI policy

Please practice only with made-up or personal information. Every work-style exercise here uses fictional sample data (in the appendices) for exactly this reason.

Never paste confidential client, cardholder, or company information into a personal AI account. Before using any AI tool for real Fiserv work, check which tools the company has approved (many large companies approve tools like Microsoft 365 Copilot) and follow those guidelines. Everything you learn here, from prompting and structuring requests to reviewing AI output, carries straight over to whatever tools you use at work.

With love and lots of confidence in you.

Getting ready

Setup guide

Allow about 30 to 45 minutes. You can do steps 1 to 3 on Day 1 and the rest when the plan reaches them.

  1. 01
    Create your Claude account and upgrade to Pro

    Go to claude.ai, sign up with a personal email, then choose Pro in Settings → Billing.

  2. 02
    Install the Claude Desktop app

    Download from claude.com/download (macOS 13+, Windows 10+). Sign in, and you'll see Chat, Cowork, and Code.

  3. 03
    Personalize Claude

    In Settings, add a few lines about yourself and how you like answers (e.g., “concise bullets, plain language, flag assumptions”). Turn on memory if you'd like Claude to remember context between chats.

  4. 04
    Turn on the right capabilities

    In Settings → Capabilities, make sure code execution and file creation is on. Artifacts and Dashboards depend on it.

  5. 05
    Add connectors (Day 6)

    Settings → Connectors → Browse. Start with Google Calendar and Google Drive, then Notion or Asana. Browse them all at claude.com/connectors.

  6. 06
    Install Claude in Chrome (Day 11)

    Add it from the Chrome Web Store, pin it, and sign in with your Claude account.

  7. 07
    Claude Code (Day 12)

    Easiest: the Code tab in the Desktop app (quickstart). For the terminal version:

    Maccurl -fsSL https://claude.ai/install.sh | bash
    Windows PowerShellirm https://claude.ai/install.ps1 | iex
    Then type claude and sign in. Full details: setup docs.

Tips that make everything easier

  • Brief, don't command. Give the who, what, why, and format, just as you'd brief a new teammate. Ask Claude to ask you questions first when a task is fuzzy.
  • Iterate in small steps. “Make the summary two sentences” works better than rewriting the whole prompt.
  • Always review. AI can be confidently wrong. Check numbers, names, and dates, and click through citations.
  • Keep permissions tight. Give Cowork one practice folder, not your whole computer, and keep “ask before acting” on for connectors and Chrome.
  • Save what works. Good prompts go in your Prompt Library, and the best ones become Skills.
  • Your usage has limits. Pro usage resets every few hours. If you hit a limit, take it as a nudge for a break. You can check usage in Settings.

Your exercise

  1. Set up. Create your Claude account at claude.ai, install the Claude Desktop app, and open Settings. Under your profile preferences, tell Claude a little about you: that you're a project coordinator in fintech, that you like clear, concise bullet points, and how you prefer to be addressed.

Week 1 · Day 2 of 14

Prompting like a project coordinator

Learn the simple structure behind great prompts, and build your first reusable template.

Time About 1 to 1.5 hours

Watch, in this order

1
Prompting 101 | Code w/ Claude
Anthropic · 24:52 · Open on YouTube ↗

Anthropic's own prompting team. Don't worry about the technical bits; listen for the structure: task, context, examples, format.

Your exercise

  1. Build a status-report template. Write a prompt you can reuse every week: who the audience is (e.g., a VP sponsor), the format (RAG status, highlights, next steps, risks, asks), tone, and length. Use placeholders like [PASTE NOTES HERE].
  2. Test it three times. Run it on the Appendix A notes. Each time, tell Claude one specific thing to improve (“shorter executive summary”, “put risks in a table”, “use our RAG definitions”). Keep the version you like best.
  3. Start a Prompt Library. Create a simple document called “My Prompt Library” and save the template there. You'll add to it all two weeks.
Done when

A kind tip Talking to Claude the way you'd brief a sharp new teammate is most of the secret.

Week 1 · Day 3 of 14

Projects, memory, and your own voice

Give Claude lasting context so you stop re-explaining your project every time.

Time About 1 hour

Watch, in this order

1
Getting started with projects in Claude.ai
Anthropic · 7:08 · Open on YouTube ↗

Your exercise

  1. Create a practice Project. In Claude, create a Project called “Project Atlas (practice)”, a made-up merchant-payments platform migration. Add the fictional charter, stakeholder list, and glossary from Appendix B as project knowledge.
  2. Write project instructions. Tell the Project how to behave: “You are my project coordination assistant. Use our RAG definitions, keep updates under 200 words, and always end with risks and asks.”
  3. Ask it to work. In the Project, ask for a stakeholder map (who needs what, how often), a first-draft RAID log, and an agenda for next week's steering committee.
  4. Teach it your writing voice. Create a custom Style (in the chat box's style menu) from two or three pieces of your own personal, non-work writing, like a travel note or a friendly email. Then ask Claude to rewrite a stiff paragraph in your style.
Done when

A kind tip Projects are like a well-organized shared drive folder with a briefing note on top. Once you have one, everything gets easier.
